# data/raw/

`car_price_prediction.csv` is a bundled, Kaggle-sourced car-listing dataset
used only to demonstrate this project's training and decomposition pipeline
end to end. It is not validated against any real-world market and, as
documented in the top-level README's **Limitations** section, shows no
meaningful correlation between `Price` and its own numeric features. Treat
it as a fixture for exercising the code, not a source of real pricing
signal.
